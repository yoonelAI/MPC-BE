MPC-BE 1.9.3 + BDMenu（蓝光光盘菜单）  版本 P2  2026-11-26
=====================================================================

打开蓝光 ISO / BDMV 文件夹 / index.bdmv 时，按光盘自己的流程播放（片头、警告、菜单），
菜单叠加在视频上，可用鼠标和键盘操作。支持普通（HDMV）菜单和 BD-J（Java）菜单。
DVD 菜单使用 MPC-BE 原生 DVD 导航。

操作
----
- 鼠标：普通菜单 移到按钮上高亮，左键点击选择；BD-J 菜单 左键 = 确定（BD-J 菜单是为遥控器设计的，
  大多不支持鼠标悬停，蓝光机软件 PowerDVD 也一样，请用方向键移动）
- 键盘：方向键 移动、回车 确认；0-9 数字键；F1-F4 = 遥控器 红/绿/黄/蓝 键
  BD-J 盘的片头、警告、菜单画面里方向键交给光盘，正片里方向键仍是快进快退
- Ctrl+M：弹出菜单（没有弹出菜单的盘则回到主菜单）
- Home：主菜单（顶层菜单）；右键 导航 → 标题菜单/根菜单 也可用
- 进度条：显示当前段落（播放列表）的时长和位置，可点击/拖动；菜单画面里不显示进度条
- PageUp / PageDown：上一章 / 下一章；右键 导航 → 章节 也可选；进度条上有章节标记
- 开盘直接放正片、不出菜单的盘：正片开始约 3 秒后自动调出菜单
- 音轨/字幕：光盘菜单里选择，播放器跟着切换；在播放器里（右键菜单、快捷键）切换，也会同步回光盘，
  光盘菜单显示的选中项保持一致。弹出菜单时字幕不消失

P2 新增
-------
- BD-J（Java）菜单：随包附带 Java 17 运行环境（bdj 文件夹），不需要系统安装 Java、不改系统设置
  BD-J 盘打开时光盘程序要先初始化，约 5 秒后才出画面
- 光盘自己的"恢复播放"（书签）可用：光盘存储在数据目录 bdj_storage
- 音轨/字幕 播放器 → 光盘 双向同步；弹出菜单时字幕显示在菜单下面
- 读盘只领先播放约 2.5 秒：光盘菜单反应及时，警告片、片头完整播放
- 窗口标题显示光盘名；查看 → 信息栏 默认关闭，显示章节标记 默认开启

自动回退（按原版方式直接放正片，没有菜单）
--------------------------------------
- 光盘加密 / 没有菜单 / libbluray 打不开 / BD-J 盘但 bdj 文件夹缺失或 Java 无法启动
- 导航模式下播放链路建不起来，或开始播放后 20 秒内读盘失败
- 上次用这张盘时播放器异常退出（崩溃保护）：该盘以后按原版方式播放。
  要恢复菜单：删除数据目录里的 bdnav_blocklist.txt

数据目录（日志、光盘存储）
------------------------
- 绿色版：播放器所在文件夹
- 安装版（Program Files 不可写）：%LOCALAPPDATA%\MPC-BE-BDMenu
- bdnav.log：运行日志（超过 2MB 自动改名为 bdnav.old.log）
- bdj_storage：BD-J 光盘的书签、设置
- 详细调试日志：在数据目录新建空文件 bdnav_debug.txt，重启播放器

已知限制
--------
- 菜单、片头、正片编码不同时（如 H.264 菜单 + 4K HEVC 正片），切换处会停在最后一帧约 1–2 秒
- BD-J 弹出菜单里的"缩小视频窗"不支持（视频仍全屏，在菜单图形下面）
- 只在少数光盘上测试过（HDMV：KARA、倩女幽魂 III UHD、罗宾汉之死 UHD；BD-J：奥德赛 UHD、可怜的东西）

彻底回退：删除或改名 bdnav.dll，播放器即恢复原版行为。
