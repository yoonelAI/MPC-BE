MPC-BE BDMenu 测试版 P1.2（蓝光 HDMV 菜单）
==========================================

打开蓝光 ISO / BDMV 文件夹 / index.bdmv 时，播放器用 libbluray 按光盘自己的流程播放（先片头/菜单），
菜单叠加在视频上，可以用鼠标和键盘操作。

操作
----
- 鼠标：移到按钮上高亮，左键点击选择
- 键盘：菜单显示时 方向键 移动、回车 确认
- Ctrl+M：弹出菜单（没有弹出菜单的盘则回到主菜单）
- Home：回到主菜单（顶层菜单）
- 原有的"导航 → 标题菜单 / 根菜单"(Alt+T / Alt+R) 也可用
- 光盘开盘直接放正片、不出菜单时，播放器会在正片开始约 3 秒后自动调出菜单

自动回退（播放方式和原版一样，没有菜单）
--------------------------------------
- 光盘有加密 / 是 BD-J(Java) 菜单盘 / 没有菜单 / libbluray 打不开
- 导航模式下播放链路建不起来
- 原因写在播放器目录下的 bdnav.log

已知限制（后续版本解决）
----------------------
- 导航模式下不能拖动进度条、时长显示为 0
- 菜单和正片编码不同的盘，切换时可能出问题
- BD-J 菜单盘暂时走原播放方式

彻底回退：删除或改名 bdnav.dll，播放器即恢复原版行为。
